# 文案驱动的视觉制作

状态：基于原始 V2.0 的修订草案 V0.1，待用户评审，未安装启用。执行本文件不意味着获得安装、配置修改或正式制作授权；先遵守当次任务范围。

## 先确定此次做什么

读取当前项目说明、交接记录和已有产物。识别交付范围：图片包、分层包、独立镜头包或无字幕粗剪。已有信息不重复询问。缺少录音时可以先做视觉策划和图片；无法确认的真实时间留空。

制作步骤和详细指导问答以 [WORKFLOW.md](../../../docs/WORKFLOW.md) 为准。数据与跨工具交接规则见 [DESIGN.md](../../../docs/DESIGN.md)。只读取当前任务需要的章节。

## 执行顺序

1. 文案理解与视觉策划：保留原意，识别主题、情绪、事实/想象和关键意象。
2. 导演分镜：明确每镜头叙事目的、对应原文、构图、运动和衔接；优先解决内容理解与重复画面。
3. 美术与图片：先做角色/风格参考和关键样张，再扩展；记录实际生成结果并检查语义、面部手部、连续性和尺寸。
4. 可选分层与动态：根据镜头选择方法，补齐背景、检查蒙版与运动边缘；不将整图位移称为真实人物动作。
5. 可选对齐与粗剪：最终时间以实际音频为准；旁白可以手工提供，不依赖特定 API。
6. 检查与交接：按约定范围提供实际文件、素材关联、检查结果、限制和下一步。

支持从任一步接续；图片或镜头范围不要求执行声音、字幕或整片合成。画风和输出规格读取项目配置，绘本电影感只是默认模板。

## 审核和返工

合并提交重要创意审核：分镜与视觉方向、关键样张、动态预览。用户已批准连续执行时按授权推进；遇到改变原意或关键形象的问题先澄清。尺寸、引用、文件存在等常规检查由执行者完成。

返工依次处理：语义、同步、角色与场景、源图、动态、转场、声音、装饰。修改时保留原件与最后可用版本，更新关联清单，不无故重做全部素材。

## 工具与证据

工具可替换。实际可用性、额度、分层效果和 API 必须按当次环境确认；不把候选接口、效果列表或提示词当作已实现结果。额度或工具不足时保存任务和参考，提供手工交接，不自动转向付费服务。

原始音色、录音和软件配置遵守用户授权，不因流程需要而默认上传、修改或购买。旧生日视频仅作参考。

只有实际完成的检查写 PASS，失败写 FAIL，未执行写 NOT_RUN，不适用写 N/A。完整解码不能替代视觉与声音验收。无法观看或听音时明确说明，并交由能完成该项的执行者复核。
