# 本地制作台实现与检查

日期：2026-11-15。

## 已实现

- 本机一页式表单：项目名、粘贴/导入文案、交付范围、画风、画幅、情绪与保留/避免事项。
- 可选配音、参考图片和视频上传，文件直接进入真实工程项目。
- 作品列表与详情，原文和要求查看、已收到文件下载、方案展开阅读、图片/视频查看。
- 修改意见、审核决定、补充文件及后续配音导入；无需在聊天中重复提供资料。
- 原文空白保留、文字草稿本机暂存、网络重试去重、失败上传不留下半成品项目。
- `web` / `inbox` 命令、Windows 双击启动入口、项目 Skill 与交接约定。

## 可用入口

[本机制作台](http://127.0.0.1:8765)，双击根目录 `启动制作台.cmd` 可以再次打开。服务只监听 127.0.0.1，没有开放公网或局域网。详细使用及执行边界见 [WEB.md](../WEB.md)。

当前页面负责材料提交、反馈和结果展示，不会自动唤醒已结束的 AI 会话。执行者使用 `avstudio inbox` 接续任务，并将真实状态和产物写回项目。
