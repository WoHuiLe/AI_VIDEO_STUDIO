# 发布验收 · 0.2.0

日期：2026-11-15。

## 已交付的工作流

网页提交并开始 → 真实 Codex 生成结构化分镜 → 审核 → 外部工具配图并逐镜头上传 → 可选透明前景 → 动态预览 / 画面确认 → 渲染和 ZIP 交付。

配图不是后台付费图像接口：用户或执行者可以用 ChatGPT 等可用图像工具，再将实际图片导入。这个边界在界面和说明中明确显示，不把提示词当生成结果。

## 检查

- 48 项自动化测试通过；包含 HTTP、真实 FFmpeg、PNG/透明图层、完整解码、缓存、音频、ZIP、重试、取消、重启恢复和分镜引用校验。
- 已用本机实际 Codex 账号执行短测试文案，获得通过 schema 与原文校验的分镜 JSON。
- 浏览器真实勾选开始并提交短测试文案，显示实际执行进度，完成后自动进入分镜审核；点击通过后进入待配图步骤。
- 正式内容、真实用户音色和旧视频没有用于自动重做。浏览器验收与所有技术素材保存在 `cache/` 下并被 Git 忽略。
- 真实图像美术质量和剪映客户端导入仍属于具体作品验收，不能由几何测试图和技术解码替代。

当前 JUnit 原始记录在本机 `docs/reports/tests.xml`，可运行 `environment/verify.ps1` 重现。安装版本与环境见锁文件。

## 仍由人工或外部工具完成

角色与美术审阅、图像生成、复杂蒙版和背景补绘、真实录音时间复核、剪映最终精修。VoiceStudio API 不是主线前置条件；没有验证的接口不硬编码。未引入付费视频生成或云端部署。
