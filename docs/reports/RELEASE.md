## 已交付的工作流

网页提交并开始 → 真实 Codex 生成结构化分镜 → 审核 → 外部工具配图并逐镜头上传 → 可选透明前景 → 动态预览 / 画面确认 → 渲染和 ZIP 交付。

配图不是后台付费图像接口：用户或执行者可以用 ChatGPT 等可用图像工具，再将实际图片导入。这个边界在界面和说明中明确显示，不把提示词当生成结果。
