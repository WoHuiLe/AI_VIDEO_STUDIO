# 动画工作台 0.4.0

双击启动制作台.cmd，打开 http://127.0.0.1:8765/ 。本机运行；默认深色，在“视图”切换浅色或收起属性。原工程和素材继续保留，旧资料提交与音频入口在 /classic，当前主线不新增配音接口。

## 开始

1. 左侧打开已有作品，或点“新建”放入文案、画风、比例与要求。默认交付为整段无字幕动画；不自动消耗模型额度。
2. “制作面板”中可用本机 Codex 设计，或复制完整任务给其他 AI，粘贴其 JSON 后校验采用。新 schema 提供可选程序场景，旧 JSON 仍可导入。
3. 分镜通过后可批量复制配图任务、扫描图片文件夹并导入。提示词与详细制作信息收在制作面板和镜头属性中。
4. 对合适的镜头，可在“动画”菜单明确选择内置窗边程序场景。它是剪纸窗边构图，不会按任意文案自动创作其他场景；不适合的镜头使用 AI 图片、自备素材或另外制作。

## 预览与编辑

- 中间播放、暂停或拖动播放头；下方点选镜头，右侧修改描述、提示词、时长、运镜或程序参数。暂停后属性选中播放头所在镜头。
- 修改描述/提示词不会直接重绘图片，需通过图像工具重做后替换。程序参数保存后重新生成预览；光线、雨、呼吸或简单步态无需模型。
- Ctrl+S 保存当前镜头，切换镜头会先保存编辑。播放前也先保存。编辑期间状态轮询不覆盖输入；若外部已修改工程，保存会报告冲突而不覆盖它。
- Ctrl+Z 撤销 / Ctrl+Shift+Z 重做（文字输入中保留原生撤销）。未保存修改先恢复；保存的工程编辑保留最近 30 次历史，重新打开仍可用。新版整片分镜或外部批量变更不套用旧历史。
- “对比上一编辑版本”对照同一镜头相对时刻的静态画面，点“返回当前版本”结束比较。不是两个完整视频的同步对比。
- 选中镜头后可前移/后移。修改时长/顺序会撤销受影响的真实旁白对齐，未录音时间只是剪辑参考。
- 右侧替换图片保留原文件，可撤销；程序场景切换为图片时保留两步编辑历史。高级制作面板中的图片可先绑定，再选择“改用已绑定图片”。

## 导出

“导出 / 交付”可选择整段无字幕动画、独立镜头、图片或真实分层素材。应用范围后确认当前画面，再生成交付。整段动画由真实 FFmpeg 编码，并连同镜头和源工程进入交付包；旧文件保留供对照，修改后需要重新确认和导出。真实分层仍要求透明前景，不能用程序场景或完整单图冒充分层。

## 独立动画示例

左下角“打开动画示例”创建一个独立 12 秒作品，三个镜头分别为夜色、靠近和清晨；不调用 AI，不读取用户文案来假称理解。可体验参数编辑、撤销、比较、顺序与正式导出。示例不是正式美术验收结果，也不表示复杂人物动作已支持。

浏览器使用与导出相同的程序图形指令。长于 300 帧的程序镜头在网页使用采样预览，正式输出仍按项目帧率逐帧绘制。不同浏览器与 Pillow 的抗锯齿可能略有差别；项目帧率不是复杂项目在任意机器上的实时播放保证。


## 进度与确认入口（0.4.1）

预览区上方常驻状态面板显示当前步骤。AI 分镜等待模型返回时显示耗时与最近更新，不编造内部推理步骤或准确百分比；镜头渲染按实际完成数显示，随后明确进入合成、检查和打包。

“分镜方案待你确认”旁点“查看分镜并确认”，在制作面板查看方案后点击“分镜通过，进入配图”。“画面与动画待你确认”则查看预览后点击“确认画面与图层”。等待图片不代表本机正在生图；外部 AI 的进度无法自动读取。状态面板会说明下一步需要什么。

顶部“后台任务”显示所有作品中正在执行的数量，可切换查看其他作品任务；“任务记录”查看本作品最近任务的实际阶段记录。未保存编辑不会阻断状态刷新，停止任务也不要求先保存。网络不可用时保留上次状态并标明连接中断，自动重试。模型详细进度不可见时，更新时间较早不等于已卡死。


## 作品菜单与回收站（0.4.1）

左侧“作品”列表每行右侧点“⋯”：打开作品、查看制作状态、停止当前制作、重命名、查看交付文件、移入回收站。停止针对当前作品的后台任务，保留已经生成的内容；没有运行任务时停止按钮禁用。任务还在停止中时需等待结束，才能重命名或移入回收站。

移入回收站前会说明范围并要求确认。文案、素材、成片和历史一起移动至本地 projects/.trash，项目列表不再显示；左侧“回收站”可还原。不会清空回收站或永久删除文件，还原遇到同编号现存作品时会拒绝覆盖。后续导出中的历史文档可能保留旧标题；重命名不改变镜头编号和素材引用。
