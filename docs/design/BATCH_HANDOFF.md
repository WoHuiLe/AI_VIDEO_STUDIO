# 跨 AI 分镜与批量配图设计

## 使用路径
1. 网页保存文案后，可用本机 Codex 或复制完整任务给其他 AI。共同规则唯一来源为 src/avstudio/resources/storyboard_rules.md，与 video-production Skill 对应。任务包含原文分段、项目要求、最近反馈、附件清单、规则、JSON schema 和当前段落的结构示例。附件需用户另行提供。
2. 外部 AI 结果可粘贴 JSON（支持 Markdown JSON 围栏）或上传 JSON。先校验再采用；错误返回可复制修正任务，原分镜不变。采用新版会重置审核和绑定，保留素材原件。
3. 分镜通过后，一键复制/下载全部配图任务。共用美术设定，按镜头顺序独立生图，用 S001.png 等编号命名，不生成拼贴。先关键样张、再其余完整图；分层另行按需准备。
4. 输入本机图片文件夹，扫描本层 PNG/JPG/WebP；严格匹配实际镜头编号前缀，展示缩略图、尺寸、已有图片替换提示、缺失、重复和未匹配。重复不自动挑选，用户整理后重新扫描。允许先导入已匹配的一部分。
5. 用户确认后复制至项目素材库并绑定；不移动/修改源文件。已有透明前景仍需同尺寸。扫描记录绑定项目与分镜版本，有效期 30 分钟；提交时重新验证文件内容，变化后要求重扫。操作失败恢复项目清单，未引用的内容寻址素材可留存，避免清理原有文件。

## 边界与验证
无新 API、无额外付费服务，不自动触发生图。文件夹仅本机、非递归，拒绝符号链接、Windows junction 和根目录；最多扫描 200 张图，单张 40MB、合计 200MB。分镜导入、批量绑定与后台任务互斥。预览只暴露扫描 token 对应图片缩略图。覆盖测试包含任务一致性、格式错误不改状态、缺失/重复匹配、过期与变更、绑定回滚、源文件保留；再在隔离项目做网页验证。
