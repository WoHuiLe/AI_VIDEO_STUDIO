# 网页制作台 · 从提交到交付

## 打开

双击根目录 `启动制作台.cmd`，打开 [本机制作台](http://127.0.0.1:8765)。素材和进度保存在当前工程 `projects/` 下。

## 一次完整制作

1. 填写项目名和文案，选择画风、比例与交付范围。配音和参考素材都可选。
2. 勾选“提交后开始设计分镜”，点击“提交并开始分镜”。真实调用本机已登录的 Codex，使用其账号额度；取消勾选则只保存，之后可点“开始设计分镜”。
3. 在作品详情阅读分镜与逐镜头设计，认可后点“分镜通过，进入配图”。不认可可补充修改意见，再点“重新设计分镜”。
4. 展开每个镜头，复制配图提示，在 ChatGPT 或你选择的图像工具里生成图片，再上传到对应镜头。背景与透明前景有独立入口。
5. 可以生成动态预览。画面与图层确认后，点“确认画面与图层”，再点“生成交付包”。
6. 在下方查看、播放和下载真实产物。之后仍可替换某镜头素材、重新确认和导出。

这是可从网页操作的制作流程，包含人工美术审核与外部工具配图，不是一键无人审核的整片 AI 视频生成服务。网页不会擅自使用付费图像 API，也不会假装已经生成图片。

## 四种交付

| 范围 | 需要的素材 | 结果 |
|---|---|---|
| 图片素材 | 各镜头完整图片 | 图片、分镜、提示和清单 ZIP |
| 分层素材 | 各镜头背景，至少一组真实透明前景 | 可继续制作的背景/图层和清单 ZIP |
| 动态镜头 | 完整图或背景/前景 | 独立 H.264 镜头及源文件 ZIP |
| 无字幕粗剪 | 镜头素材，可选旁白 | 顺序直切粗剪、独立镜头、源文件 ZIP |

没有配音也能开始，不编造语音时间。含旁白的粗剪需要在网页时间轴中听音，填写并确认真实起止秒数；镜头必须连续并覆盖旁白，程序拒绝静默截断。声音精修、复杂转场和字幕可在剪映继续。

## 配图与分层

完整图片或干净背景必须不透明。透明前景应是带真实 alpha 的 PNG，并与背景使用同一画布大小。替换素材保留原文件，使当前画面审核失效；正式导出前需要再次确认。技术解码不能代替人物、构图和情绪审核。

每个镜头有图像提示与分层建议。用其他 AI 做分镜时，下载“分镜格式说明”让其按 JSON Schema 输出，从“使用其他 AI 的分镜 / 导入方案”上传，之后同样先审核。

## 状态、停止与恢复

- 待处理：仅保存资料，尚未启动。
- 处理中：有真实后台任务，可看当前步骤并停止。
- 待你确认：分镜或预览已生成，等待审核。
- 待配图：分镜通过，等待实际图片/图层。
- 已交付：产物已生成并经过文件与媒体检查。
- 需要处理：执行失败或中断，可看原因并重试。

本机队列串行执行，避免占满 CPU 或重复消耗额度。同一项目重复点击相同任务会复用当前任务。服务重启会标记中断，不自动重复调用；重新点击开始即可重试。

反馈、补充附件和替换配音都在作品详情底部的“补充资料或提出修改”中进行。正在执行时需先等待或停止。首次提交不需要审核空成果。分镜提出修改后需重新设计，新版通过后再继续；不是直接沿用旧审核。

## 安装与检查

运行 `environment/install.ps1 -Dev` 安装，`environment/start-web.ps1` 打开，`environment/verify.ps1` 检查。已有 Codex 登录被复用，不保存或显示密钥。未登录时可先保存资料或导入其他 AI 的分镜。

代码更新后运行 `environment/restart-web.ps1` 重启，`environment/stop-web.ps1` 停止本工程服务。重启会保留全部项目；同一工作目录只能有一个执行器，避免重复消耗额度。Windows 脚本只会停止记录且命令匹配本工程的进程。

只监听 127.0.0.1，不是公网服务。每次最多 20 个附件、总计 100 MB。文字草稿本机暂存，刷新后未上传附件需重新选择。

## 项目交接

`planning/submission.json` 保存状态与要求，`feedback.json` 保存反馈，`director.json` 保存经过校验的分镜，`shot_assets.json` 保存图层绑定，`project.json` 保存实际渲染数据，`work/jobs/` 保存任务记录。

Codex 使用只读执行方式，只要求返回 JSON；本工程校验后自行写入，不把模型输出作为代码。接口依据 [官方非交互文档](https://learn.chatgpt.com/docs/non-interactive-mode)，并对照本机帮助。实测结果见 [发布验收报告](reports/RELEASE.md)。


## 批量制作（0.3.0）

保存资料后打开作品详情，可选“用本机 Codex 设计分镜”，或展开“其他 AI 设计分镜”复制完整任务。把其他 AI 返回的 JSON 粘贴或上传，点击“校验并采用分镜”；报错时复制修正任务给原 AI。采用新版会重置审核和绑定，源文件保留。任务包包含共同制作规范 1.0、原文、要求、反馈、格式和示例；参考附件须另行提供，网页不会把本机文件路径交给外部 AI 读取。

分镜通过后，在“整批配图，统一导入”点击“一键复制全部配图任务”或下载。交给图像工具先做关键样张、再扩展；每镜头一张独立完整图，按实际编号保存，如 S001.png、S002.png，勿生成拼贴或把编号画进图片。工具无法命名时下载后手工重命名。

把存图的本机文件夹完整路径填入网页，扫描后检查缩略图、缺失、重复及尺寸提示，再确认导入已匹配图片。支持编号原名或编号加描述（如 S001_窗边.png），不按日期或文件顺序猜测；重复编号需先整理。只扫描本层，最多 200 张、单张 40MB、合计 200MB。扫描后修改文件需重新扫描。部分镜头可以先导入，后续补齐。导入复制至项目素材库，不移动或覆盖源文件。

第一轮放不透明完整图。透明前景单独通过镜头卡片上传，并保持与背景相同画布；分层范围仍至少需要一组真实分层。素材齐全后沿用画面审核、动态预览与交付流程。以上操作不自动调用图像 API。
