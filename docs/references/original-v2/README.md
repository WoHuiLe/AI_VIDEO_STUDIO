# AI 绘本电影化叙事视频制作 Skill V2.0

本目录是 V2.0 Skill 包。

-   `SKILL.md`：完整制作规范与执行流程。
-   `templates/storyboard_template.csv`：分镜时间轴模板。
-   `templates/asset_manifest_template.csv`：素材清单模板。
-   `templates/QA_CHECKLIST.md`：制作验收清单。

使用时将整个目录放入 Agent/Skills 的技能目录中，并确保入口文件名为
`SKILL.md`。 本 Skill
是新版本规范，不会自动修改或重渲染此前已完成的视频。
