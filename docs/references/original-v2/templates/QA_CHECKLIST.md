# V2.0 视频质量验收清单

## A. 叙事与音画同步

-   [ ] 文案与实际录音已核对
-   [ ] 关键句均有明确视觉表达
-   [ ] 关键动作与语音时间点匹配
-   [ ] 没有明显的语义错配
-   [ ] 没有按字数平均分配时长
-   [ ] 场景转场有明确理由

## B. 画面和美术

-   [ ] 角色外观、发型和服装一致
-   [ ] 人物脸部、手部和肢体自然
-   [ ] 环境、道具与文案一致
-   [ ] 远景、中景、近景、特写有变化
-   [ ] 没有大量重复姿势和重复画面
-   [ ] 图片分辨率满足目标输出
-   [ ] 无意外文字、Logo、水印或拼图

## C. 动画和镜头

-   [ ] 镜头运动平滑
-   [ ] 前中后景视差自然
-   [ ] 图层边缘无明显穿帮
-   [ ] 环境动态不过量
-   [ ] 无明显抖动、闪烁或跳帧
-   [ ] 转场自然且不过度
-   [ ] J-cut / L-cut 使用合理

## D. 声音

-   [ ] 原始旁白完整保留
-   [ ] 人声清楚且无削波
-   [ ] 配乐不盖住人声
-   [ ] 音乐情绪与叙事匹配
-   [ ] 环境音符合场景
-   [ ] 开头和结尾无突兀截断

## E. 输出与技术

-   [ ] 分辨率、帧率符合要求
-   [ ] 视频与音频流存在
-   [ ] 无字幕母版没有字幕流
-   [ ] 若要求全画面无文字，已检查图片内文字
-   [ ] ffprobe 检查通过
-   [ ] 完整解码检查通过
-   [ ] 人工观看抽查通过
-   [ ] 下载文件路径已验证
-   [ ] 制作报告已生成
