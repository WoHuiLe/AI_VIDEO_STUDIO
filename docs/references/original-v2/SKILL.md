# AI 绘本电影化叙事视频制作 Skill

## 0. 版本定位

**版本：V2.0.0**

V2.0 是在 V1
图片配旁白工作流基础上的制作方法升级，不是对旧视频的自动返工，也不要求修改任何已完成的视频。

### 用户已确认的长期制作方向

  ----------------------------------------------------------------------------------------------
  维度                    默认选择
  ----------------------- ----------------------------------------------------------------------
  画面风格                日系清新治愈、精致绘本电影感

  动态方式                静态插画分层动画为主

  核心优先级              画面质量与独白叙事同步

  成本限制                优先现有 ChatGPT Plus 和免费本地工具，不新增订阅

  本地硬件                不要求独立 NVIDIA GPU；本地处理优先 CPU 可运行

  旁白                    优先使用用户本人提供的原始录音

  字幕                    默认不烧录字幕，交付干净无字幕母版

  制作目标                不是图片轮播，而是有镜头语言、场景变化、情绪节奏和声音空间的叙事短片
  ----------------------------------------------------------------------------------------------

### V2.0 相比 V1 的关键变化

1.  从"先生成图片、再按时长拼接"改为"先分析声音和文案、再设计镜头、最后生成素材"。
2.  从"一句或一段对应一张图片"改为"按语义和动作拆成多个镜头"。
3.  从单张图片轻微放大缩小，升级为前景、中景、背景分层和受控的 2.5D
    动画。
4.  从重复情侣插画，升级为人物、环境、动作、细节、意境和时间变化等多种镜头。
5.  从只做淡入淡出，升级为匹配剪辑、动作衔接、声音先行/延续和少量柔和叠化。
6.  从只混合配音与背景音乐，升级为音乐情绪曲线和克制的环境音设计。
7.  增加分镜审核、低清预览、分段验收和返工机制。
8.  默认输出无字幕母版，字幕作为独立资产处理。

## 1. Skill 目标与适用范围

本 Skill 用于制作以下类型的视频：

-   生活记录、日常感悟、个人成长；
-   生日信、爱情独白、纪念日短片；
-   旅行回忆、人物故事、情绪叙事；
-   有真实旁白、需要 AI 辅助视觉表达的 B 站横屏视频。

默认目标是 2--3 分钟的 16:9
横屏视频。更长的视频应按章节分段设计，不得机械增加图片数量来填充时长。

### 1.1 作品质量目标

成片必须同时具备：

-   **叙事对应**：观众听到的内容与看到的画面在语义、情绪和动作上相符；
-   **镜头变化**：远景、中景、近景、特写和环境镜头有节奏地组合；
-   **视觉连续**：人物、服装、色彩、光线和空间关系尽量统一；
-   **动态克制**：画面有生命力，但不晃动、不乱动、不为了动态而动态；
-   **声音完整**：人声清晰，音乐不抢戏，环境音只在需要时出现；
-   **技术可靠**：画面无闪烁、黑帧、意外裁切，音频无爆音，文件可正常播放。

### 1.2 不属于默认范围的内容

-   不默认使用付费 AI 视频生成平台；
-   不要求用户购买额外会员；
-   不依赖本地大型视频扩散模型；
-   不将大量无关素材、转场和特效当作"电影感"；
-   不为了追求镜头数量而牺牲语义准确性；
-   不擅自修改用户已经完成的旧视频。

## 2. 总体制作原则

### 2.1 音频优先，但画面必须参与叙事

用户提供了本人配音时：

1.  保留原始音频，永不覆盖；
2.  先确认实际录音时长、语速、停顿和情绪变化；
3.  用实际录音建立主时间轴；
4.  镜头切换依据语义、动作、情绪和声音节奏共同决定；
5.  不允许先随意拼好画面，再强行把旁白塞进时间线。

"音频优先"不等于机械地每句话结束就切画面。画面可以在一句话中途切换，也可以跨越一句话延续，但必须有明确的叙事理由。

### 2.2 画面质量和叙事同步优先于速度

-   先做分镜审核，再批量生成素材；
-   关键场景可以多轮生成和筛选；
-   重要人物镜头不接受明显变脸、肢体错误和低清源图；
-   发现镜头不匹配时，优先重做镜头，不用字幕、转场或滤镜掩盖问题；
-   允许适当减少镜头数量，不能用大量低质量画面凑数。

### 2.3 原始素材与工作素材分离

-   原始录音、文案、用户照片只读保存；
-   所有音频处理、图片裁切、分层、动画和渲染放入工作目录；
-   不覆盖用户原始文件；
-   每次重要渲染保留版本号，避免覆盖最后一个可用版本。

### 2.4 不虚报能力和验收

-   只有真正生成并检查过的图片，才可称为已生成；
-   只有实际渲染并播放检查的视频，才可称为成片；
-   仅通过 ffprobe 不代表画面质量通过；
-   仅通过完整解码不代表叙事同步通过；
-   未实际听音、看画面或检查字幕时，必须标记为未检查。

## 4. 七阶段制作流程

``` text
阶段 1：文案与音频分析
        ↓
阶段 2：语义分段与精确时间轴
        ↓
阶段 3：导演分镜与审核
        ↓
阶段 4：角色设定、美术设定、素材生成
        ↓
阶段 5：分层动画与独立镜头制作
        ↓
阶段 6：声音设计、剪辑与整体合成
        ↓
阶段 7：预览验收、修改、高清导出
```

每个阶段必须有明确产物。前一阶段存在重大问题时，不要直接进入后续批量生产。

------------------------------------------------------------------------

## 5. 阶段一：文案与原始录音分析

### 5.1 文案分析

先识别：

-   主题和核心表达；
-   叙事视角；
-   人物关系；
-   时间顺序；
-   地点和场景；
-   真实事件与想象场景；
-   情绪变化；
-   关键句和必须保留的信息。

不得只根据关键词生成字面插图。要理解句子在整篇故事中的作用。

### 5.2 情绪曲线

将整篇文案标注为情绪阶段，例如：

1.  开场和引入；
2.  轻柔、亲近；
3.  幸福回忆；
4.  憧憬和想象；
5.  低落、矛盾或反思；
6.  理解、和解；
7.  希望和承诺；
8.  收束。

具体阶段由文案决定，不要求每条视频都具备全部阶段。

### 5.3 音频检查

使用 ffprobe 查看基础信息：

``` bash
ffprobe -v error \
  -show_entries format=duration,size \
  -show_entries stream=codec_name,sample_rate,channels \
  -of json narration_original.wav
```

记录：

-   实际时长；
-   采样率；
-   声道；
-   编码；
-   是否有削波、爆音或严重底噪；
-   是否有开头或结尾被截断。

### 5.4 音频主时间轴

用户实际说出的内容是时间轴依据。文案与录音不一致时：

-   不擅自假定录音完全按照文案朗读；
-   以实际录音为准标注时间；
-   记录漏读、增读、口误和重复；
-   未经用户授权，不替换成 AI 配音或重新合成用户声音。

------------------------------------------------------------------------

## 6. 阶段二：语义分段与逐句时间校准

这是 V2.0 的关键阶段，直接决定画面是否与独白同步。

### 6.1 不按字数平均分配时间

禁止将整篇文案按字符数量平均分配到音频时长。中文语速、停顿、情绪重音和句子长度不成线性关系。

### 6.2 推荐时间校准方法

1.  获取音频波形和时长；
2.  通过 VAD 或静音检测寻找候选停顿；
3.  使用语音识别文本作为辅助（如果可用）；
4.  将识别文本与原始文案逐句核对；
5.  逐句听音，标记开始、结束、停顿和重音；
6.  标记每个关键短语的准确时间范围；
7.  形成可供分镜使用的音频时间轴。

静音检测示例：

``` bash
ffmpeg -i narration_original.wav \
  -af silencedetect=noise=-35dB:d=0.15 \
  -f null -
```

静音检测只是候选边界。轻声说话、呼吸、背景噪声和情绪停顿都可能导致错误，必须人工复核。

### 6.3 时间轴字段

建议 `audio_timeline.csv` 至少包含：

  字段           含义
  -------------- ----------------
  segment_id     语义段编号
  start          开始秒数
  end            结束秒数
  transcript     实际说出的文字
  emotion        情绪
  emphasis       重点词或重音
  pause_before   前置停顿
  pause_after    后置停顿
  confidence     时间校准可信度
  notes          校准说明

### 6.4 同步质量要求

-   关键句不能配错场景；
-   关键动作应在旁白提到时发生或有意提前/延后；
-   不要让人物已经完成动作，旁白才刚开始描述动作；
-   允许使用声音先行或画面延续，但要有明确设计；
-   不能用"整段大致对上"代替关键句同步。

------------------------------------------------------------------------

## 7. 阶段三：导演分镜设计与审核

### 7.1 先做分镜，再生成素材

禁止先批量生成一堆图片，再尝试把它们拼到旁白里。

分镜是文案、音频与视觉素材之间的桥梁。每个镜头必须回答：

1.  这一刻观众听到了什么？
2.  观众应该看到什么？
3.  画面要表达事实、动作、情绪还是象征？
4.  为什么要在这个时间切镜？
5.  镜头如何运动？
6.  与上一个镜头如何衔接？

### 7.2 镜头数量参考

对 2--3 分钟叙事视频：

-   建议规划约 20--30 个镜头；
-   可准备约 15--22 张不同的高质量基础画面；
-   一张图可以裁切出不同景别，但必须有明显构图差异；
-   不得为了达到数量而生成重复、无意义镜头；
-   画面需要持续变化，但不应为了变化过快切镜。

这些是规划参考，不是强制配额。故事节奏优先于镜头数量。

### 7.3 镜头类型组合

每条视频应有意识地组合以下类型：

  类型           典型内容                         主要作用
  -------------- -------------------------------- --------------------
  人物情感镜头   对视、微笑、拥抱、牵手、依偎     表达关系和情绪
  环境氛围镜头   枫叶路、海边、星空、雨夜、窗边   建立空间和气氛
  生活细节镜头   信件、手指、蜡烛、照片、咖啡     增加真实感和细腻度
  动作镜头       走路、回头、写字、奔跑、递信     推动视觉叙事
  象征意境镜头   阳光、云层、流星、花朵、雨滴     表达抽象情绪
  时间变化镜头   四季、老年相伴、相册、日落       表达时间和未来

不要让整条视频只有情侣拥抱、牵手和站立对视。

### 7.4 景别与视角

镜头规划应包含：

-   大远景 / 远景：建立地点、空间和人物关系；
-   全景：展示人物完整动作；
-   中景：展示两人互动；
-   近景：表现人物情绪；
-   特写：手、信件、眼神、蜡烛、雨滴等；
-   主观视角：让观众像人物一样观察场景；
-   过肩镜头：适合对话、读信和注视。

连续镜头避免一直使用同一景别和同一机位。

### 7.5 分镜表字段

`storyboard.csv` 至少包含：

  字段                 含义
  -------------------- --------------------------
  shot_id              镜头编号
  start / end          时间范围
  transcript           对应的实际独白
  narrative_purpose    镜头叙事目的
  visual_description   画面描述
  shot_type            景别
  camera_angle         机位
  camera_motion        运镜
  subject_action       人物动作
  environment_motion   环境动态
  transition_in/out    入场和出场衔接
  asset_id             关联素材
  sync_anchor          对应的语音关键词或动作点
  review_status        待审核 / 通过 / 返工
  notes                备注

### 7.6 分镜审核门槛

正式批量生成素材前，先向用户展示：

-   文案分段；
-   镜头时间；
-   每个镜头画面描述；
-   镜头类型和运动；
-   主要角色和场景；
-   关键转场。

优先让用户审核故事理解和画面方向。未经用户要求，不必每个镜头都逐一确认，但关键人物形象、重大情绪场景和结尾设计应优先审核。

------------------------------------------------------------------------

## 8. 阶段四：角色设定、美术设定与素材生成

### 8.1 统一角色设定（Character Bible）

在生成场景图之前，建立角色参考：

-   角色年龄感（仅作视觉设定）；
-   发型、发色、脸型和主要特征；
-   服装和配色；
-   身高比例和体态；
-   角色关系和互动方式；
-   不同场景下允许变化的服装；
-   必须保持一致的识别特征。

同一角色在不同画面中不能无故变脸、换发型或改变年龄感。

如果用户提供真实人物参考照片，应仅用于用户授权的项目，尊重照片中的人物外观，不推断敏感属性。

### 8.2 统一美术设定（Visual Style Guide）

默认方向：

-   日系清新治愈系绘本电影感；
-   柔和水彩质感与精致数字插画结合；
-   奶油色、暖白、浅杏、樱花粉、柔和暖橙；
-   自然光、夕阳光、窗边光和柔和光晕；
-   细腻但不过度繁杂的背景；
-   人物表情克制、自然；
-   构图有电影感，画面留白合理。

避免：

-   低龄幼儿化或夸张表情；
-   过度油腻的高饱和滤镜；
-   每张图都使用相同的粉色背景；
-   不必要的光斑、粒子和镜头光晕；
-   AI 乱码文字、随机 Logo、水印；
-   拼图、分格、海报式多画面布局（除非用户明确要求）。

### 8.3 素材类型

优先按镜头用途生成，而不是只生成"漂亮的情侣图"：

1.  场景背景图；
2.  人物主体图；
3.  前景遮挡元素；
4.  关键道具图；
5.  局部特写图；
6.  过渡镜头或氛围镜头。

### 8.4 分层素材原则

对适合做 2.5D 的画面，优先准备：

-   背景层：天空、远山、建筑、房间、远景树木；
-   中景层：人物、桌子、街道主体；
-   前景层：树叶、花枝、窗框、雨滴、光斑等；
-   独立道具层：信纸、照片、蜡烛、杯子等。

若生成工具无法直接输出分层文件，可采用：

-   先生成完整构图；
-   再通过图像编辑生成干净背景或独立元素；
-   使用人工蒙版或图像分割将主体分离；
-   检查边缘、头发、手指和透明区域；
-   不得把未检查的自动抠图直接用于重要人物镜头。

### 8.5 图像生成提示词模板

``` text
沿用项目角色设定和视觉风格设定。

场景：
[明确地点、时间、天气和环境]

人物：
[人物位置、外观、服装、关系]

动作：
[人物正在做什么，动作处于哪个瞬间]

情绪：
[温柔、安心、期待、释然、坚定等]

镜头：
[景别、机位、构图、主体位置、前中后景]

光线与色彩：
[时间光线、主色调、光源方向]

画面要求：
16:9 横向电影构图，高清细节，人物比例自然，
统一日系治愈绘本电影质感，柔和水彩与精致数字插画结合。
画面不包含字幕、Logo、水印和随机文字。
不出现拼图、多格排版、重复人物、额外肢体或变形手部。
```

### 8.6 图像质量检查

每张图必须检查：

-   分辨率和宽高比；
-   人物面部、手部和肢体；
-   人物与角色设定的一致性；
-   背景透视和物体关系；
-   是否存在乱码文字或水印；
-   是否适合裁切和镜头运动；
-   是否有足够空间容纳运动；
-   画面是否符合对应独白的情绪。

重要镜头不合格时重新生成，不用模糊、锐化或滤镜掩盖源图缺陷。

## 9. 阶段五：静态插画分层动画与 2.5D 镜头

这是 V2.0 的主要视觉升级方向。

### 9.1 动画目标

静态插画不应只是缓慢放大或缩小。应通过前、中、后景的不同运动速度，以及少量环境动态，让观众感受到空间、空气和时间。

### 9.2 2.5D 视差

典型结构：

``` text
前景：树叶、花枝、窗框、雨滴、光斑
          ↓（轻微移动，速度相对较快）
中景：人物、桌面、主要道具
          ↓（小幅移动）
背景：天空、远山、建筑、室内墙面
          ↓（移动幅度最小）
```

原则：

-   前景运动幅度可以略大；
-   背景运动幅度最小；
-   人物主体尽量稳定；
-   不同层不能出现明显脱离、穿帮或边缘空洞；
-   视差幅度必须克制，不能造成眩晕；
-   镜头运动应服务于叙事，不应每张图都使用同一套运动。

### 9.3 可用的镜头运动

  运镜                  适用内容                     注意事项
  --------------------- ---------------------------- ----------------------
  缓慢推进              情感靠近、读信、人物表情     不要把人物推到画面外
  缓慢拉远              回忆、孤独、结尾、环境关系   保留主体辨识度
  横向平移              街道、海边、室内空间         运动速度连续
  轻微垂直移动          天空、树木、建筑和人物       避免无意义上下晃动
  固定机位 + 环境动效   雨、雪、烛光、星空、海浪     适合安静情绪
  前景遮挡运动          树叶、窗帘、路过物体         可用于自然转场

### 9.4 环境动态库

根据镜头内容按需加入：

-   枫叶、花瓣、雪花缓慢飘落；
-   海浪往复、海面反光；
-   云层缓慢移动；
-   星星轻微闪烁、流星划过；
-   雨滴沿玻璃滑落；
-   烛火轻微摆动；
-   窗帘和树叶轻微摆动；
-   纸张翻动、信封打开；
-   光影缓慢变化。

不能所有效果同时出现。每个镜头通常选择 1--2 种主要动态即可。

### 9.5 动作真实性

-   人物走路、拥抱、牵手等复杂动作，不应仅靠缩放图片伪装成真实动作；
-   需要明显动作时，优先设计动作前后两个镜头、遮挡转场或局部特写；
-   不具备真实动画能力时，应诚实使用镜头语言表达，不宣称为真实角色动画；
-   人物脸部和手部不适合做强烈变形或大幅运动。

### 9.6 防抖与稳定性

-   统一项目帧率；
-   避免每帧不连续的坐标变化；
-   运镜曲线使用平滑缓动；
-   不要在镜头中途突然反向；
-   不要对同一张图连续叠加多次缩放；
-   避免低分辨率图像放大后再大幅推进；
-   每个镜头先独立预览，再合成整片。

如果无法保证运动稳定，使用固定机位加环境动态，优于不稳定的复杂运镜。

## 10. 阶段六：镜头衔接与电影化剪辑

### 10.1 不把淡入淡出当成唯一转场

转场应由镜头内容决定。可用方法：

  方法       示例                             适用情况
  ---------- -------------------------------- ----------------
  动作匹配   手伸向信封，下一镜头手打开信封   动作连续
  形状匹配   圆形烛光切换到夕阳               构图相似
  色彩匹配   暖橙夕阳切换到室内暖灯           色彩连续
  前景遮挡   树叶经过镜头时切换场景           户外场景
  光线过渡   画面被阳光覆盖后切换             梦境、回忆
  柔和叠化   两个安静场景缓慢交叠             情绪延续
  声音先行   下一场景海浪声先出现             场景空间变化
  声音延续   画面已切走，雨声仍保留           情绪或空间延续

### 10.2 J-cut 与 L-cut

-   J-cut：下一场景声音先于画面出现；
-   L-cut：当前场景声音延续到下一画面。

例如从枫叶路转到海边，可以先出现海浪声，再切换到海边画面。

### 10.3 转场克制原则

-   不连续使用多种花哨转场；
-   不在每个镜头之间强行叠化；
-   情绪强烈的句子可以直接切镜，保留力量；
-   静谧场景可以用较长叠化；
-   镜头运动方向相近时优先动作匹配；
-   转场时间必须计入总时长，不能破坏旁白同步。

## 11. 阶段七：音乐、旁白与环境音设计

### 11.1 声音层次

默认声音结构：

1.  用户原始旁白；
2.  背景音乐；
3.  场景环境音；
4.  少量动作音效。

旁白始终是第一优先级。音乐和音效不能影响听清每一个关键字。

### 11.2 音乐情绪曲线

音乐应随着叙事变化，而不是从头到尾使用同一音量、同一密度。

  叙事阶段     音乐方向
  ------------ --------------------------
  开场         简单、轻柔、留白
  幸福回忆     温暖钢琴，可加入柔和弦乐
  憧憬未来     逐渐丰富，但不要过度煽情
  情绪低谷     减少乐器和节奏密度
  理解与和解   逐渐恢复温暖
  情绪升华     适度增强旋律和和声
  结尾         回归简单，留下余韵

### 11.3 环境音

按场景使用，不要为了"丰富"而堆满音效：

-   翻纸、拆信封；
-   脚步、衣物轻微摩擦；
-   海浪、海风；
-   树叶、风声；
-   雨声、雨滴；
-   夜晚虫鸣；
-   烛火或轻微室内环境声。

环境音必须与画面空间匹配。室内镜头不应无故出现强烈海风，星空场景也不应出现突兀的城市交通声。

### 11.4 混音要求

-   人声保持清晰和自然；
-   不为了响度把人声压得扁平；
-   配乐在人声出现时适当降低；
-   片头、片尾音乐自然淡入淡出；
-   防止峰值削波；
-   检查手机扬声器和普通耳机上的可懂度。

音乐和音效必须确认使用许可。免费不等于可商用，AI
生成也不自动意味着没有版权限制。

## 12. 字幕策略：默认无字幕母版

### 12.1 默认交付

默认视频必须：

-   不烧录字幕；
-   不包含外挂字幕轨；
-   保留完整画面；
-   保留用户原声和配乐；
-   可以直接导入剪映或其他软件识别字幕。

### 12.2 独立字幕

用户需要时再生成 SRT：

-   以实际录音为准；
-   按语义拆句；
-   对照实际发音校准；
-   不按字数平均分配时间；
-   检查开头、中段和结尾；
-   字幕不得遮挡人物面部和关键道具。

### 12.3 图片内文字

无字幕视频仍可能出现 AI
图片内的随机文字。若用户要求全画面无文字，必须在生成阶段明确禁止，并在素材质检时检查；不能仅靠删除字幕轨来保证。

## 13. 分段渲染与验收机制

### 13.1 不直接一次性渲染最终版

建议采用：

1.  先生成关键镜头；
2.  输出低分辨率或低码率预览；
3.  检查画面和独白同步；
4.  检查镜头运动和转场；
5.  检查人物一致性；
6.  修改不合格镜头；
7.  完成全片预览；
8.  最后输出高清成片。

### 13.2 分段验收

至少抽查：

-   片头；
-   每个情绪段落的第一镜头；
-   所有关键句对应的镜头；
-   主要场景转换；
-   情绪低谷；
-   情绪升华；
-   最后 10--15 秒。

### 13.3 质量验收表

  维度         验收问题
  ------------ ------------------------------------
  叙事同步     画面是否准确表达当前独白？
  镜头语言     是否有景别变化和合理视角？
  画面多样性   是否避免大量重复人物姿势？
  角色一致性   人物是否前后一致？
  画面质量     是否清晰、无变形、无明显 AI 瑕疵？
  动态效果     是否平滑、稳定、不过度？
  转场         是否自然，有没有无意义的花哨效果？
  色彩         是否像同一部作品？
  音频         人声是否清楚，音乐是否抢戏？
  节奏         是否存在拖沓或切换过快？
  结尾         是否有足够时间完成情绪收束？

### 13.4 返工优先级

发现问题时按以下顺序处理：

1.  语义与画面不匹配；
2.  旁白时间不同步；
3.  角色或场景严重不一致；
4.  图片质量问题；
5.  动画抖动、穿帮；
6.  转场生硬；
7.  音乐和环境音问题；
8.  细节美化。

先修复影响理解的问题，再处理装饰性问题。

## 14. 技术实现与本地工具

### 14.1 工具原则

优先使用用户已经拥有的工具和免费本地工具：

-   ChatGPT：文案分析、分镜设计、图片生成、提示词、画面检查；
-   FFmpeg：视频合成、音频混合、转码、抽帧、媒体检查；
-   Python：素材命名、时间轴数据处理、批量任务和报告；
-   剪映免费版：需要手工精修时进行字幕、关键帧和局部剪辑；
-   Codex：仅在需要时辅助开发本地批处理工具，不作为每次视频制作的必需步骤。

不要求独立显卡。CPU 可以完成常规图片缩放、静态镜头合成、音频混合和 H.264
编码，但速度可能慢于有硬件加速的设备。

### 14.2 推荐分工

  工作             推荐方式
  ---------------- -----------------------------------------
  文案和情绪分析   ChatGPT
  分镜设计         ChatGPT
  图片生成         ChatGPT 图像生成
  角色和风格参考   ChatGPT + 用户确认
  分层素材准备     图像编辑、蒙版或手工处理
  简单 2.5D 动画   FFmpeg / Python 图像合成
  复杂时间线微调   剪映免费版
  音频混音         FFmpeg
  视频编码         FFmpeg CPU 编码
  批量辅助脚本     Python；需要时由 Codex 辅助
  质量验收         ffprobe、完整解码、抽帧、人工观看和听音

### 14.3 Codex 使用边界

Codex 轻度使用即可，适合一次性建立：

-   项目目录初始化脚本；
-   图片素材批量检查脚本；
-   分镜 CSV 转时间线脚本；
-   批量镜头渲染脚本；
-   ffprobe 验收脚本；
-   输出文件整理和报告生成脚本。

不要每条视频都重新开发一套工具。不要将大量 Codex
额度消耗在重复性的素材生成或简单文件整理上。

### 14.4 FFmpeg 编码参考

``` bash
ffmpeg -y -i final_timeline_input \
  -c:v libx264 -preset medium -crf 18 \
  -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ar 48000 \
  -movflags +faststart \
  output.mp4
```

具体输入和滤镜根据实际工程调整。不能把示例命令当作已经执行的命令。

## 17. 完整技术验收

### 17.1 文件存在性

确认最终文件确实存在，大小合理，不能仅根据文件名创建下载链接。

### 17.2 媒体流检查

``` bash
ffprobe -v error \
  -show_entries format=duration,size \
  -show_entries stream=index,codec_type,codec_name,width,height,r_frame_rate,sample_rate,channels \
  -of json output.mp4
```

### 17.3 完整解码检查

``` bash
ffmpeg -v error -i output.mp4 -f null -
```

### 17.4 无字幕验收

-   不包含 subtitle stream；
-   不烧录字幕；
-   若要求全画面无文字，还必须检查 AI 图片是否带字。

### 17.5 人工观看检查

技术检查不能替代人工观看。至少应检查：

-   片头和片尾；
-   每个重要分镜；
-   所有转场；
-   人物面部和手部；
-   运动边缘和遮罩；
-   音画同步；
-   音乐是否盖住人声。

## 18. 常见问题与解决策略

### 18.1 画面与独白不同步

原因： - 时间轴按字数平均分配； - 只按大段而不是关键短语分镜； -
镜头时长没有结合实际语速； - 场景切换没有对应动作锚点。

处理： - 回到原始音频； - 重新校准关键句时间； - 重新设计镜头切换点； -
优先修改分镜，不要靠整体移动字幕或画面来掩盖局部错误。

### 18.2 图片切换生硬

原因： - 只使用直接切换或固定时长淡入淡出； -
前后镜头构图、方向和色彩差异过大； - 缺少环境声音过渡。

处理： - 设计动作匹配； - 使用前景遮挡； - 使用声音先行和声音延续； -
统一镜头运动方向； - 在适合的段落使用柔和叠化。

### 18.3 画面内容单一

原因： - 只生成情侣站立、牵手和拥抱； - 缺少环境、道具、动作和特写； -
没有景别变化。

处理： - 增加环境建立镜头； - 增加手、信件、照片、脚步等特写； -
增加动作镜头； - 增加象征性意境镜头； - 通过分镜审核检查重复画面。

### 18.4 角色前后不一致

处理： - 先固定角色参考图； - 固定发型、服装和色彩； -
生成时引用同一角色参考； - 对关键镜头进行人工筛选； -
发现明显变脸时重新生成，不使用滤镜掩盖。

### 18.5 2.5D 动画抖动或穿帮

处理： - 检查主体蒙版边缘； - 检查图层是否存在缺失背景； -
减少视差幅度； - 统一帧率； - 使用平滑运动曲线； -
不能修复时退回固定画面加环境动态。

### 18.6 图片不够清晰

处理： - 优先重新生成高清源图； - 避免多次缩放和有损压缩； -
重要人物画面使用近景和中景； - 不依赖锐化制造不存在的细节； -
检查输出编码和码率。

### 18.7 音乐盖住人声

处理： - 降低配乐； - 使用 sidechain ducking； -
减少音乐低频或中频冲突； - 在人声重点句处适当留白； -
用普通耳机和手机扬声器复听。

## 19. 默认执行规则

用户提供新文案和录音后，按以下顺序执行：

1.  确认文案、录音、标题和目标平台；
2.  检查音频和文案，不覆盖原始文件；
3.  分析叙事结构和情绪曲线；
4.  建立实际语音时间轴；
5.  设计逐镜头分镜表；
6.  展示分镜和视觉方向供用户审核；
7.  建立角色设定和美术设定；
8.  生成高质量、多类型场景素材；
9.  检查人物一致性和图片质量；
10. 为适合的场景准备前景、中景和背景分层；
11. 制作 2.5D 动画、镜头运动和环境动态；
12. 设计匹配转场、声音先行和声音延续；
13. 混合用户旁白、音乐和必要的环境音；
14. 先输出低清预览；
15. 检查叙事同步、画面质量、声音和节奏；
16. 修改不合格镜头；
17. 输出无字幕高清母版；
18. 用户需要时再输出 SRT 或烧录字幕版；
19. 完成技术验收和人工抽查；
20. 提供最终文件和制作报告。

### 19.1 默认不要做的事

-   不要先生成图片再拼接旁白；
-   不要按字数平均分配镜头时长；
-   不要用同一张图片支撑多个语义差异很大的段落；
-   不要只用情侣拥抱图填满整条视频；
-   不要对每张图片机械套用相同的缩放动画；
-   不要每个镜头都用淡入淡出；
-   不要为了"电影感"堆砌光斑、粒子和转场；
-   不要未经授权更改原始录音；
-   不要默认烧录字幕；
-   不要为了节省时间跳过分镜审核和预览验收；
-   不要把未检查的结果描述为已通过。

## 20. 一句话制作准则

**先听懂声音，再理解故事；先设计镜头，再生成画面；让每一个画面都服务于当下的独白，让每一个动态和转场都有叙事理由。**

最终目标不是"让 AI
生成更多图片"，而是用有限的高质量素材，讲出一段连贯、细腻、有情绪、有电影感的故事。
